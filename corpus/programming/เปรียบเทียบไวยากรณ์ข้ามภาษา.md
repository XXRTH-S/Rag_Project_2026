# เปรียบเทียบไวยากรณ์ข้ามภาษา

## การประกาศตัวแปรในแต่ละภาษา

| ภาษา | ตัวแปรทั่วไป | ค่าคงที่ | ต้องระบุชนิดไหม |
|---|---|---|---|
| Python | `age = 30` | ไม่มีจริง ใช้ตัวพิมพ์ใหญ่เป็นข้อตกลง | ไม่ต้อง |
| JavaScript | `let age = 30;` | `const age = 30;` | ไม่ต้อง |
| Java | `int age = 30;` | `final int AGE = 30;` | ต้อง |
| C | `int age = 30;` | `const int AGE = 30;` | ต้อง |
| Go | `age := 30` | `const Age = 30` | ไม่ต้อง แต่ชนิดคงที่หลังประกาศ |

Python และ JavaScript เป็น dynamic typing คือตัวแปรเปลี่ยนชนิดได้ตอนโปรแกรมทำงาน ส่วน Java, C และ Go เป็น static typing คือชนิดถูกล็อกไว้ตั้งแต่คอมไพล์

## การแสดงผลออกหน้าจอ

| ภาษา | คำสั่ง |
|---|---|
| Python | `print("สวัสดี")` |
| JavaScript | `console.log("สวัสดี");` |
| Java | `System.out.println("สวัสดี");` |
| C | `printf("สวัสดี\n");` |
| Go | `fmt.Println("สวัสดี")` |

C ไม่ขึ้นบรรทัดใหม่ให้เอง ต้องใส่ `\n` เอง ต่างจากภาษาอื่นในตารางที่ขึ้นบรรทัดใหม่ให้อัตโนมัติ

## การแทรกค่าตัวแปรลงในข้อความ

```python
name = "สมชาย"
print(f"สวัสดีคุณ {name}")
```

```javascript
const name = "สมชาย";
console.log(`สวัสดีคุณ ${name}`);
```

```java
String name = "สมชาย";
System.out.println("สวัสดีคุณ " + name);
```

```go
name := "สมชาย"
fmt.Printf("สวัสดีคุณ %s\n", name)
```

Python ใช้ f-string, JavaScript ใช้ template literal ที่ครอบด้วยเครื่องหมาย backtick ส่วน Java นิยมต่อข้อความด้วยเครื่องหมายบวก และ Go ใช้ตัวระบุรูปแบบเหมือน C

## การขึ้นบล็อกคำสั่ง

Python ใช้การย่อหน้าบอกขอบเขตของบล็อก ส่วน JavaScript, Java, C และ Go ใช้วงเล็บปีกกา

ผลที่ตามมาคือใน Python การย่อหน้าผิดทำให้โปรแกรมทำงานผิดหรือคอมไพล์ไม่ผ่าน ในขณะที่ภาษาอื่นการย่อหน้าเป็นเพียงความสวยงามที่ไม่มีผลต่อการทำงาน

## การเปรียบเทียบข้อความ

| ภาษา | วิธีที่ถูก | สิ่งที่ต้องระวัง |
|---|---|---|
| Python | `a == b` | ใช้ได้ตรงไปตรงมา |
| JavaScript | `a === b` | `==` แปลงชนิดให้อัตโนมัติจนได้ผลแปลก |
| Java | `a.equals(b)` | `==` เทียบว่าเป็นวัตถุเดียวกัน ไม่ใช่เนื้อข้อความ |
| C | `strcmp(a, b) == 0` | `==` เทียบที่อยู่ของพอยน์เตอร์ |
| Go | `a == b` | ใช้ได้ตรงไปตรงมา |

นี่คือจุดที่ผู้ย้ายภาษาพลาดบ่อยที่สุด โดยเฉพาะ Java และ C ซึ่งเขียน `==` แล้วโปรแกรมไม่แจ้งข้อผิดพลาด แต่ผลลัพธ์ผิดเงียบ ๆ

## เลขตำแหน่งของอาร์เรย์

ทุกภาษาในเอกสารนี้เริ่มนับตำแหน่งแรกของอาร์เรย์จากศูนย์ สมาชิกตัวแรกคือ `arr[0]` และสมาชิกตัวสุดท้ายของอาร์เรย์ที่มี n ตัวคือ `arr[n-1]`

การเข้าถึงตำแหน่งที่เกินขอบ Python และ Java จะโยนข้อผิดพลาดให้เห็นทันที ส่วน C ไม่ตรวจให้เลยและไปอ่านหน่วยความจำที่ไม่ใช่ของเรา ซึ่งอันตรายกว่ามากเพราะโปรแกรมอาจทำงานต่อไปด้วยข้อมูลขยะ

## การจัดการข้อผิดพลาด

| ภาษา | รูปแบบ |
|---|---|
| Python | `try` / `except` / `finally` |
| JavaScript | `try` / `catch` / `finally` |
| Java | `try` / `catch` / `finally` และมี checked exception ที่คอมไพเลอร์บังคับให้ดัก |
| C | คืนรหัสสถานะแล้วให้ผู้เรียกตรวจเอง ไม่มีกลไกในภาษา |
| Go | คืนค่า error เป็นค่าที่สองแล้วตรวจด้วย `if err != nil` |

แนวคิดต่างกันชัดเจนสองแบบ คือให้ข้อผิดพลาดกระโดดขึ้นไปหาผู้ดักอย่าง Python, JavaScript และ Java กับให้ข้อผิดพลาดเป็นค่าธรรมดาที่ต้องตรวจทุกครั้งอย่าง C และ Go

## การจัดการหน่วยความจำ

Python, JavaScript, Java และ Go มีตัวเก็บขยะที่คืนหน่วยความจำที่ไม่ได้ใช้ให้อัตโนมัติ ผู้เขียนจึงไม่ต้องจัดการเอง

C ไม่มีตัวเก็บขยะ ผู้เขียนต้องเรียก `malloc` จองและ `free` คืนเอง ลืมคืนก็เกิด memory leak คืนซ้ำสองครั้งก็ทำให้โปรแกรมพัง นี่คือเหตุผลหลักที่ C เร็วแต่เขียนให้ปลอดภัยยาก
