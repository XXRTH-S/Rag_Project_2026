ตัวอย่างการฝัง chat widget

หน้านี้จำลองเว็บของลูกค้าที่ฝัง widget ไว้ ปุ่มคุยอยู่มุมขวาล่าง

วิธีฝัง

<script src="http://localhost/widget.js" defer></script>

ถ้า widget อยู่คนละโดเมนกับ API ให้ระบุปลายทางด้วย

<script src="https://rag.example.com/widget.js"
        data-api="https://rag.example.com" defer></script>

ข้อควรรู้

ตอนนี้ /api/chat ต้องเข้าสู่ระบบก่อน widget จึงใช้ได้เฉพาะผู้ที่ล็อกอินแล้ว ในเบราว์เซอร์เดียวกัน ถ้าต้องการเปิดให้คนทั่วไปใช้โดยไม่ต้องล็อกอิน ต้องเพิ่ม endpoint สาธารณะที่จำกัดขอบเขตเอกสารและพึ่ง rate limit กับ origin allowlist เป็นด่านป้องกัน ซึ่งเป็นการตัดสินใจด้านความปลอดภัยที่ต้องพิจารณาก่อน
